## Задание 1

### Задача 1. Точка координат

**Текст задачи**

Создайте сущность `Point` (Точка), расположенную на двумерной плоскости, которая описывается:

- Координата X: число
- Координата Y: число
- Может возвращать текстовое представление вида `"{X;Y}"`

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

**Алгоритм решения**

1. Инициализация потока ввода `Scanner` и запуск бесконечного цикла главного меню.
2. Вывод меню на экран и считывание выбора пользователя с помощью метода `readInt()` (с защитой от ввода некорректных символов).
3. Если выбран пункт 1:
   - Создаётся массив из 3 объектов класса `Point`.
   - В цикле от 1 до 3 происходит запрос координат X и Y у пользователя.
   - С помощью метода `readDouble()` данные считываются и валидируются (проверяется, является ли ввод числом).
   - На основе введённых данных через конструктор создаются экземпляры класса `Point` и сохраняются в массив.
4. После ввода всех данных в цикле происходит обход массива точек.
5. Для каждой точки вызывается переопределённый метод `toString()`, который форматирует координаты в требуемый вид `{X;Y}` и выводит результат на консоль.
6. Программа возвращается к главному меню.

## Задание 2
### Задача 1. Прямая

**Текст задачи**

Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:
   • Координата начала: Точка
   • Координата конца: Точка
   • Может возвращать текстовое представление вида “Линия от {X1;Y1} до {X2;Y2}”
Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте
линии со следующими характеристиками:
1. Линия 1 с началом в т. {1;3} и концом в т.{23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там
же, где заканчивается линия 2. Таким образом, если положение первой или второй линии
меняется, то меняется и третья линия.
4. После создания всех трех объектов измените координаты первой и второй линий, причем
сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям
пункта 3.
5. Измените координаты первой линии так, чтобы при этом не изменились, координаты третьей
линии.

**Алгоритм решения**

1.	Создание Линии 1: Пользователь вводит координаты начала и конца (по умолчанию {1;3} и {23;8}). Создается объект `Line`, внутри которого конструктор создает два новых объекта `Point`.
2.	Создание Линии 2: Пользователь вводит координаты горизонтальной линии (по умолчанию {5;10} и {25;10}). Аналогично создаются два новых объекта `Point`.
3.	Создание Линии 3: Используется конструктор `Line(Point startPoint, Point endPoint)`, которому передаются ссылки на уже существующие объекты: `line1.getStartPoint()` (начало Линии 1) и `line2.getEndPoint()` (конец Линии 2). Таким образом, Линия 3 не создает новых точек, а использует те же объекты в памяти, что и Линии 1 и 2.
4.	Изменение координат: Пользователь вводит новые координаты для начала Линии 1 и конца Линии 2. Изменение происходит через методы `setX()` и `setY()` объектов `Point`, полученных через геттеры `getStartPoint()` и `getEndPoint()`. Поскольку Линия 3 хранит ссылки на те же объекты Point, её координаты автоматически обновляются.
5.	Изменение без влияния на Линию 3 (пункт 5): Пользователь вводит новые координаты только для конца Линии 1 (через `line1.getEndPoint().setX/setY`). Начало Линии 1 не изменяется, так как оно является началом Линии 3. Следовательно, Линия 3 остается без изменений, а Линия 1 меняет только свою конечную точку.

**Алгоритм решения**

2.	В цикле пользователь вводит название каждого города. Пустые названия отклоняются с предложением повторить ввод.

## Задание 5
### Задача 1. Дроби

**Текст задачи**

Создайте сущность Дробь	со	следующими	особенностями:
   • Имеет	числитель:	целое	число
   • Имеет	знаменатель:	целое	число
   • Дробь	может	быть	создана	с	указанием	числителя	и	знаменателя	
   • Может	вернуть	строковое	представление	вида	“числитель/знаменатель”
   • Может	выполнять	операции	сложения,	вычитания,	умножения	и	деления	с	другой	Дробью	
или	целым	числом.	Результатом	операции	должна	быть	новая	Дробь	(таким	образом,обе	
исходные	дроби	не	изменяются)
Затем	необходимо	выполнить	следующие	задачи:
1. Создать	несколько	экземпляров	дробей.
2. Написать	по	одному	примеру	использования	каждого	метода.
3. Вывести	на	экран	примеры	и	результаты	их	выполнения	в	формате	«1/3	*	2/3	=	2/9»
4. Посчитать f1.sum(f2).div(f3).minus(5)

**Алгоритм решения**

1.	Пользователь выбирает пункт 6 в главном меню.
2.	Программа запрашивает ввод числителя и знаменателя для трех дробей `(f1, f2, f3)` и одного целого числа. При вводе знаменателя срабатывает проверка: если введен 0, выводится ошибка и предлагается повторить ввод.
3.	При создании объекта `Fraction` в конструкторе автоматически вычисляется наибольший общий делитель (НОД) числителя и знаменателя, благодаря чему дробь сразу сокращается до несократимого вида.
4.	Программа демонстрирует работу перегруженных методов арифметических операций `(sum, minus, mul, div)`. Каждый метод принимает либо другую дробь, либо целое число, и возвращает новый объект `Fraction`, не изменяя исходные операнды.
5.	Результаты операций выводятся в консоль в требуемом формате (например, 1/3 * 2/3 = 2/9).
6.	В конце вычисляется цепочка методов `f1.sum(f2).div(f3).minus(5)`. Поскольку каждый метод возвращает новую дробь, вызовы выстраиваются в цепочку `(chaining)`, и итоговый результат выводится на экран.
